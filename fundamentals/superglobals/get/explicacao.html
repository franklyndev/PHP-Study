📌 Superglobal $_GET no PHP

A superglobal $_GET é um array do PHP usado para capturar informações enviadas pela URL através da query string.

🔗 Exemplo de URL

produto.php?id=25&categoria=games

O PHP automaticamente transforma isso em: 

$_GET['id'] = 25;
$_GET['categoria'] = "games";

💻 Exemplo em PHP

<?php

$id = $_GET['id'];

echo "Produto: $id";

?>

🛒 Analogia da Loja Online

Imagine uma loja online. Cada produto possui um ID único.

Quando o usuário clica em um produto, o site muda a URL:

produto.php?id=25

O $_GET funciona como um mensageiro entre o navegador e o servidor.

“O usuário clicou no produto de ID 25.”

Então o backend pega esse ID e procura o produto correto no banco de dados. 

<?php

$id = $_GET['id'];

buscarProduto($id);

?>

Isso permite que uma única página carregue milhares de produtos diferentes.

⚡ Exemplos Reais de Uso

🔍 Pesquisa

search.php?produto=teclado 
$produto = $_GET['produto'];

🎮 Filtro de Categoria

produtos.php?categoria=games

📄 Paginação

produtos.php?pagina=2

💰 Ordenação

produtos.php?ordenar=preco

🔒 Por que não usar GET para tudo?

Tudo enviado pelo GET fica visível na URL.

Então informações sensíveis não devem usar GET.

❌ Exemplo inseguro

login.php?senha=123456

Qualquer pessoa conseguiria ver a senha na URL.

🧠 Diferença Mental

Tecnologia Função
$_GET Buscar ou visualizar dados pela URL
$_POST Enviar dados ocultos/formulários
$_SESSION Guardar dados temporários no servidor
Cookies Guardar dados no navegador

📌 Resumo Final

O $_GET é usado para ler informações enviadas pela URL. Ele é muito utilizado para:

  • Navegação entre páginas
  • Buscar produtos
  • Filtros
  • Paginação
  • Ordenação

Ele é rápido, simples e essencial para aplicações web dinâmicas.
